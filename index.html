📖 關於本應用

🗺️ 區段勘查小幫手 v1.1.7

一個強大的都市計畫輔助工具，整合 OpenStreetMap、台灣官方地圖數據， 支援設施查詢、多邊形分析、道路寬度評估、都市計畫色系管理等功能。

✨ 核心功能

  • 🔍 設施查詢：按名稱、類別、距離或區域快速查詢 POI
  • 🔷 多邊形分析：繪製、編輯、統計區域內設施分佈
  • 🛣️ 道路分析 (v1.1.7 新增)：計算加權平均寬度、標註比例、道路密度
  • 🎨 色系管理 (v1.1.7 新增)：動態顏色指定、都市計畫標準色系
  • 🔗 GeoJSON/SHP 匯入：支援多種圖層格式與欄位標籤
  • 📊 資料匯出：Excel、GeoJSON、Shapefile、截圖
  • 📍 自動定位：GPS 自動定位到目前位置
  • 🎯 路線規劃：基於 OSRM 的實時路線距離計算

🛠️ 技術棧

  • 地圖框架：Leaflet.js + Leaflet Draw
  • 空間分析：Turf.js
  • 地理編碼與路由：OpenStreetMap Nominatim + OSRM
  • 資料查詢：Overpass API
  • 資料處理：XLSX、Shapefile-js
  • 底圖服務：NLSC (台灣國土測繪中心) WMTS + 自訂 WMS
