區段勘查小幫手
版本: v1.1.5 (完整版)
發行日期: 2026年08月16日
授權: MIT License + ODbL Attribution

核心功能

  • 基於 OpenStreetMap 和國家地理資訊系統 NLSC 的地圖整合
  • Overpass API POI 設施查詢與分析
  • OSRM 路由服務與距離計算
  • 新北市都市計畫圖層 (基本圖/詳細圖/帶標示)
  • 多邊形繪製、編輯與管理
  • GeoJSON/SHP 檔案匯入與匯出
  • 自動地理位置更新功能
  • Excel 匯出報告
